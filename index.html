01 시작 전 준비물

VR러너 추가에 필요한 자료 4가지

1‑3·1‑4는 아바타와 절대 같은 값을 쓰면 안 됩니다 — 같은 계좌(앱키)는 기동 시 즉시 차단되고, 같은 봇 토큰은 텔레그램 폴링 충돌(409)을 일으킵니다. 각 카드가 만들어 내는 값이 곧 설정 마법사에 입력할 항목입니다.

01
Google Sheets

이얀 VR V7 시트 사본 만들기

VR러너는 매수·매도 사다리·자금 상태를 시트에서 읽고 체결 결과를 기록합니다. 배포용 템플릿 시트를 열어 내 계정으로 사본을 만듭니다.

  • 템플릿 → 파일 → 사본 만들기
  • 사본의 주소창 URL 전체 복사
  • 복사본은 모델 모드 — 02장에서 실거래(1)로 전환. Data 탭은 자동 시세라 그대로
→ 마법사 시트 URL
02
Google Cloud Console

서비스계정 JSON + 시트 공유

아바타를 이미 쓰고 있다면 기존 서비스계정을 재사용할 수 있습니다 — 이 VR 시트 사본에 그 이메일을 다시 공유만 하면 됩니다.

  • Sheets API 사용 설정(신규 생성 시)
  • 서비스계정 생성 → 키 추가 → JSON 다운로드
  • JSON의 client_email 을 시트에 편집자로 공유
  • 공유 누락 시 시트 접근 오류
→ 마법사 서비스계정 JSON(파일)
03
openapi.kiwoom.com

(별도) 키움 앱키·시크릿키 + IP 등록

주문·조회·시세·환전을 키움 REST API로 처리합니다. 아바타와 다른 별도 실전 계좌로 키를 발급받고 실행 PC의 IP를 등록합니다.

  • VR 전용 별도 계좌 — 아바타 계좌 재사용 불가(기동 즉시 차단)
  • 앱키·시크릿키 발급 (다운로드 1회)
  • 실행 PC 공인 IP 등록(최대 10개)
  • 미등록 IP 호출은 거부됨
→ 마법사 앱키 · 시크릿키
04
Telegram

(별도) 텔레그램 봇 토큰 + chat_id

실행·체결·환전 알림과 조회/일시정지 명령에 씁니다. 아바타와 다른 새 봇을 만드세요.

  • VR 전용 새 봇 — 같은 토큰이면 409 폴링 충돌
  • @BotFather → /newbot → 봇 토큰
  • chat_id: 봇에 메시지 후 getUpdates
  • chat_id는 아바타와 같아도 무방(알림만 한 대화에 섞임)
→ 마법사 봇 토큰 · chat_id
🔒
앱키·시크릿키·서비스계정 JSON·봇 토큰 은 실제 계좌와 시트의 열쇠입니다. 타인과 공유하거나 공개된 곳에 올리지 마세요.
02 시트 설정

기본 설정 + 시작일 초기 매수

준비물 01에서 복사한 내 VR 시트 사본을 열어 Tracker 탭 기본 설정을 채우고, 시작일에 최초 투입금액의 80%를 매수해 Trades 탭에 기록하면 시트 준비가 끝납니다. 복사한 시트는 모델 모드(B11=0)로 오니, 실제 운용하려면 아래처럼 실거래 모드(1)로 바꿉니다.

Tracker 기본 설정
셀이름넣을 값
B4종목운용할 종목 티커 — 예: TQQQ
B5시작일가능한(최근) 거래일로 설정 — 이 날부터 전략이 시작됩니다
B6최초 투입금액처음 넣을 원금(USD) — 예(가상): $5,750. 이 금액이 예수금(POOL)의 시작값이 됩니다
B11거래 모드반드시 1(실거래) — 복사 직후엔 0(모델)이라 꼭 바꿉니다
💡
나머지 설정(B8 수수료율·B9 사다리 단계·B10 리밸런싱 주기·B12 사다리 폭·B13 실시간 행)은 시트 기본값을 그대로 두면 됩니다. 적립·인출(B7)은 다음 장(03 적립·자금)에서 설정합니다. K열 상태·사다리표(P5:W16)는 전부 자동 계산이라 건드리지 않습니다.
필수 시작일 초기 매수 — 투입금액의 80%

전략은 시작일에 원금의 80%로 종목을 사서 시작합니다(나머지 20%는 예수금 POOL로 남아 이후 매수·리밸런싱에 쓰입니다). 이 첫 매수만 사람이 직접 하고 Trades 탭에 적어 주면, 이후는 VR러너가 이어받습니다.

  1. 실제 매수 — 시작일(B5)에 키움에서 최초 투입금액의 80%만큼 종목을 매수합니다(예: B6=$5,750 → 약 $4,600 매수).
  2. Trades 탭에 기록 — 체결 결과를 Trades 탭 A:E 한 줄에 적습니다: 날짜(=시작일) · 수량 · 체결단가 · 수수료 · 거래금액. (같은 날 나눠 샀으면 여러 줄로 적어도 시트가 날짜별로 합산합니다.)
  3. Tracker에서 확인 — Tracker 일별표의 시작일 행에 매수 수량·금액이 뜨고, 상단 K4(보유 수량)·K6(POOL, ≈ 원금의 20%)이 잡히면 시트 준비 완료입니다.
시세 Data 탭은 그대로 둡니다 — 자동 로딩

Data 탭은 A1 셀의 GOOGLEFINANCE 수식이 시세 전체를 자동으로 채웁니다. VR러너는 이 값을 읽기만 하고 절대 쓰지 않으므로, Data 탭은 손대지 말고 그대로 두면 됩니다(예전의 “값 고정 마이그레이션”은 필요 없어졌습니다).

⚠️
Data 탭에 직접 값을 써넣지 마세요 — GOOGLEFINANCE 자동 영역(스필)을 덮어쓰면 표가 #REF! 로 무너집니다. 시세가 며칠 지연돼 매매 안전장치에서 “가격 지연”으로 걸리면, 시트 메뉴 [VR+] > 가격 새로고침으로 갱신하세요(러너가 대신 쓰지 않습니다).
03 적립 · 자금 이체

적립금 정하고, 원화로 자동이체 걸어두기

정기 적립을 원하면 Tracker B7에 사이클(2주)당 적립금을 적고, 그 자금을 원화로 증권계좌에 자동이체해 둡니다 — 사이클 시작일마다 VR러너가 알아서 원→달러 환전해 넣습니다.

Tracker 적립·인출 설정
셀이름넣을 값
B7적립금(사이클당)부호가 방향을 정합니다 — 양수: 2주마다 넣을 금액(USD, 예: $100 · $200) / 음수: 그 절대값만큼 자동 인출(달러→원) / 0(빈칸): 환전 안 함
💡
인출 전용 셀(B14~B16)과 4주 인출 주기는 시트 개정으로 폐지되었습니다 — 이제 B7 하나의 부호가 적립/인출을 정하고, 인출도 적립과 같은 사이클(2주) 시작일에 처리됩니다(한 사이클에 적립·인출 중 하나만). 켜고 끄는 별도 스위치는 없습니다 — 시트 값(B7)이 곧 자동/수동을 결정합니다.
자금 적립금은 원화로 자동이체 — 매주 절반씩

B7은 2주(한 사이클)치 적립금입니다. 사이클 시작일에 환전이 나가려면 그때까지 계좌에 원화가 준비돼 있어야 하므로, 매주 B7의 1/2을 원화로 증권계좌에 자동이체해 두는 것을 권합니다.

  • 예: B7=$200(2주치) → 매주 $100어치 원화를 증권계좌로 자동이체.
  • 원화로 넣어두면 됩니다 — 사이클 시작일 한국시간 오전 10시에 VR러너가 원→달러로 자동 환전해 적립합니다.
  • 환전에 성공하면 그 즉시 Trades 탭 입금란에 자동 기록됩니다(중복 환전 방지 로직 내장).
  • 인출(B7 음수)은 원화 준비가 필요 없습니다 — 달러 예수금에서 원화로 환전됩니다.
⚠️
원화 잔액이 부족하면 그 사이클 적립 환전이 실패하고 텔레그램 경고가 옵니다 — 자동이체 금액·주기가 B7과 맞는지 확인하세요.
04 다운로드 & 설치

받아서 실행하면 트레이에 상주합니다

VR 러너는 설치가 필요 없는 단일 실행 파일(VR.exe)입니다. 아바타 트레이(Avatar.exe)와는 완전히 별개 프로그램이라, 같은 PC에 둘 다 설치해도 서로 독립적으로 동작합니다.

  1. 릴리즈 페이지에서 최신 VR.exe 를 내려받습니다. 최상단 최신 릴리즈의 첨부 파일을 받으세요.
    https://github.com/gbsmfather/vr-releases/releases
  2. 받은 VR.exe 를 원하는 폴더(예: C:\VR\)에 두고 더블클릭해 실행합니다.
  3. “Windows의 PC 보호”(SmartScreen) 경고가 뜨면 추가 정보 → 실행 을 누릅니다.
  4. 작업표시줄 시계 옆 트레이에 VR 아이콘이 나타납니다(아바타 아이콘과 다릅니다 — 둘 다 실행 중이면 두 개가 보입니다). 안 보이면 ^(숨겨진 아이콘 표시)를 확인하세요.
🔄
업데이트는 자동입니다. VR 트레이는 매일 프리장 시작 때 VR 전용 릴리즈에서 새 버전을 확인해 스스로 업데이트하고, 실행 중이던 VR러너는 업데이트 후 자동으로 다시 시작됩니다(아바타 업데이트와는 완전히 분리된 경로입니다 — 서로의 버전·릴리즈에 영향을 주지 않습니다). 지금 바로 확인하려면 트레이 우클릭 → “업데이트 확인” 을 누르세요.
05 VR러너 추가 · 설정 마법사

준비한 값을 넣어 계좌를 등록

VR 트레이 우클릭 → “VR러너 추가…” 를 누르면 내 컴퓨터 안에서만 열리는 설정 페이지가 뜹니다. 아래 값을 입력하세요 — 키·토큰은 붙여넣기 확인을 위해 평문으로 표시됩니다.

💡
이 마법사 화면은 아바타 마법사와 같은 골격을 재사용합니다 — 페이지 제목 등에 “아바타” 문구가 남아 있을 수 있지만, 아래 입력 항목은 VR 전용 6가지 값으로 자동 구성되니 신경 쓰지 않아도 됩니다.

키움앱키VR 전용 키움 App Key준비물 03

  1. 입력 확인 — 값 형식뿐 아니라 VR 시트 레이아웃(Tracker · B4 종목 · J2 검증 띠 · B11 실거래모드=1) · 키움 토큰 발급 · 텔레그램 봇 을 실제로 점검합니다.
  2. 이상 없으면 저장 — 이름 중복만 검사한 뒤 설정 페이지가 자동으로 닫히고 VR 트레이 “VR러너” 목록에 추가됩니다.
⚠️
같은 키움 계좌(앱키)를 아바타나 다른 VR러너에 함께 등록하면 저장은 되더라도 실행하는 순간 “이미 실행 중” 오류로 즉시 막힙니다. 같은 텔레그램 봇 토큰을 쓰면 폴링 충돌(409)이 납니다. 반드시 별도 계좌·별도 봇 토큰을 준비하세요(01 준비물 참고).
06 VR러너 실행

계좌를 클릭하면 러너가 시작됩니다

  1. VR 트레이 우클릭 → “VR러너” 에 마우스를 올리면 등록된 계좌 목록이 나옵니다.
  2. 실행할 계좌 이름을 클릭 — 시작되면 메뉴에 체크 표시가 붙습니다.
  3. VR러너는 하루 1회 배치로 동작합니다. 기동하면 텔레그램으로 “🚶 VR러너 출근했습니다” 알림이 오고, 상세 상태는 /status 로 확인할 수 있습니다.
📈
실행 상태·이벤트(주문 접수·체결·환전 등)는 텔레그램으로 통지되고 구글 시트(Tracker·Trades 탭)에도 기록됩니다. 프로그램 창을 계속 열어둘 필요가 없습니다.
자동 자동 시작 — 트레이가 뜰 때 계좌를 자동 실행
  1. VR 트레이 우클릭 → “자동 시작” 에 마우스를 올리면 계좌 목록이 나옵니다.
  2. 자동 시작할 계좌를 클릭해 체크합니다(다시 클릭하면 해제).
  3. 설정은 다음 트레이 실행부터 적용됩니다 — 트레이가 뜨면 체크된 계좌가 자동 실행되고 풍선 알림으로 알려줍니다.
관리 이름 변경 — VR러너 표시 이름 바꾸기

추가할 때 정한 이름은 나중에 바꿀 수 있습니다 — 표시 이름만 바뀌고 설정·데이터·자동 시작 여부는 그대로입니다.

  1. 바꿀 VR러너를 먼저 중지합니다(실행 중인 계좌는 목록에 나오지 않습니다).
  2. VR 트레이 우클릭 → “이름 변경” 에 마우스를 올려 VR러너를 클릭합니다.
  3. 브라우저에 작은 입력 창이 열립니다 — 새 이름을 입력하고 저장하면 끝입니다.
참고 하루가 어떻게 돌아가나요

VR러너는 하루를 세 국면(prep → place → settle)으로 나눠 미국 장을 따라 움직이고, 적립·인출 환전은 이와 별도로 한국시간 기준으로 처리합니다.

국면시점하는 일
prep개장 전시트를 읽어 오늘 사다리(계획)를 확인하고 텔레그램으로 알림 — 시세(Data)는 시트가 자동 유지하므로 러너는 읽기만 함

자동환전 적립·인출 자동 환전

적립·인출(B7의 부호)은 사이클 시작일 한국시간 오전 10시에 US 장과 별개로 자동 처리됩니다 — B7이 양수면 원→달러 적립, 음수면 그 절대값만큼 달러→원 인출, 0이면 환전 없음. 성공 시 Trades 탭 입금란에 자동 기록됩니다. (설정·자동이체는 03 적립·자금 참고.)

07 VR러너 종료

계좌 중지 → 앱 종료, 두 단계

VR 트레이는 실행 중인 계좌가 하나라도 있으면 종료되지 않도록 막혀 있습니다.

6-1 계좌 중지
  1. VR 트레이 우클릭 → “VR러너” → 실행 중(체크된) 계좌 클릭.
  2. 확인창에서 예 를 누르면 중지가 시작됩니다.
  3. 진행 창이 뜨고, 정지가 끝나면 자동으로 닫힙니다.
💡
VR 주문은 마감 직전(기본 60분 전)에만 접수되고 마감 직후 settle 국면에서 자동 정리되므로, 일반적인 시간대에 중지하면 취소할 미체결 주문이 없는 경우가 많습니다.
6-2 트레이 종료
  1. 모든 계좌를 중지하면 VR 트레이 “종료” 가 활성화됩니다.
  2. “종료” 클릭 → 확인창에서 예 → VR 트레이가 종료되고 아이콘이 사라집니다(아바타 트레이가 함께 떠 있었다면 영향받지 않습니다).
⚠️
강제 종료·전원 차단 등 정상 절차가 아닌 종료에서는, 다음 실행 시 이어서 처리됩니다(그날 처리한 국면은 반복하지 않도록 상태가 저장돼 있습니다). 종료는 반드시 위 절차를 따르세요.
🗑️
더 이상 쓰지 않는 계좌는 중지한 뒤 VR 트레이 우클릭 → “VR러너 삭제…” 에서 지울 수 있습니다(확인창이 뜹니다). 실행 중인 계좌는 삭제 목록에 나타나지 않습니다.
