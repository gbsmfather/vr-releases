RSI RSI-VR 한눈에

RSI로 사고팔고, 매번 같은 금액만큼

매일 종가 기준으로 RSI(14)를 보고, 기준 아래면 사고 위면 팝니다. VR러너는 원래 사람이 매일 손으로 하던 ① 신호·주문 확인 ② 종가 주문 접수 ③ 체결 확인·기록 ④ 적립·인출 환전을 전부 자동으로 처리합니다.

매수
RSI(14) ≤ 44

기준 이하인 날, 1회 금액만큼

종가(LOC)로 매수합니다. 투자 가능 현금(예수금 − 예비금)이 모자라면 있는 만큼만 삽니다.

매도
RSI(14) ≥ 72

기준 이상인 날, 1회 금액만큼

종가(LOC)로 매도합니다. 보유가 모자라면 있는 만큼만 팝니다. 그 사이면 관망(주문 없음).

금액
매수·매도 공통

1회 금액 = (연초 기준금액 + 올해 실현손익 × 75%) ÷ 30

평가금(시세)은 쓰지 않아 시세가 올라도 부풀지 않고, 폭락해도 매수 여력이 유지됩니다.

📅
첫날엔 주식을 사지 않고 RSI가 기준 아래로 내려올 때까지 현금으로 기다립니다. 매년 5월 마지막 수요일에는 전년도 실현손익 × 22%를 정기 인출합니다 — 연초부터 예비금으로 떼어 두었다가 내보냅니다(03장).

01 시작 전 준비물

VR러너 추가에 필요한 자료 4가지

03·04는 아바타와 절대 같은 값을 쓰면 안 됩니다 — 같은 계좌(앱키)는 기동 시 즉시 차단되고, 같은 봇 토큰은 텔레그램 폴링 충돌(409)을 일으킵니다. 각 카드가 만들어 내는 값이 곧 설정 마법사에 입력할 항목입니다.

01
Google Sheets

RSI-VR 시트 사본 만들기

VR러너는 매수·매도 주문과 자금 상태를 시트에서 읽고, 체결·입출금을 시트에 기록합니다. 배포용 시트(“[시뮬] 이얀 RSI-VR”) 사본 만들기를 눌러 내 드라이브에 복사합니다.

  • 링크 → [사본 만들기] (먼저 둘러보려면 보기 전용으로 열 수 있습니다)
  • 사본의 주소창 URL 전체 복사
  • 복사본은 모델(백테스트) 모드 — 02장에서 내 시작일·금액·실거래(1)로 전환
  • [RSI-VR] 메뉴를 처음 누르면 스크립트 권한 승인을 묻습니다 — 허용
→ 마법사 시트 URL
02
Google Cloud Console

서비스계정 JSON + 시트 공유

아바타를 이미 쓰고 있다면 기존 서비스계정을 재사용할 수 있습니다 — 이 RSI-VR 시트 사본에 그 이메일을 다시 공유만 하면 됩니다.

  • Sheets API(·Drive API 권장) 사용 설정(신규 생성 시)

02 시트 설정

기본 설정 + Trades 에 초기 입금 1줄

준비물 01에서 복사한 내 RSI-VR 시트 사본을 열어 Tracker 기본 설정을 내 운용에 맞게 바꾸고, Trades 탭에 초기 입금 1줄을 적으면 시트 준비가 끝납니다. 사본은 모델 모드(B10=0)로 오니 실제 운용하려면 실거래 모드(1)로 바꿉니다.

필수 Trades 탭 — 초기 입금 1줄

RSI-VR은 첫날 주식을 사지 않습니다. 원금을 현금(예수금)으로 넣어 두고, RSI가 매수 기준 아래로 내려오는 날부터 VR러너가 1회 금액씩 사 들어갑니다. 사람이 할 일은 원금이 들어왔다는 기록 1줄뿐입니다.

  1. Trades 탭을 엽니다 — 왼쪽 A:E는 매매 기록, 오른쪽 G:H는 입출금 칸입니다.
  2. G:H 첫 줄에 날짜 = 운용 시작일(B5), 입출금 = 최초 투입금액(B6)을 적습니다 — 예(가상): 2026-09-14 · 5750. 날짜는 Tracker 표 첫 행(18행) 날짜와 같아야 그날로 합산됩니다.
  3. Tracker에서 확인 — 표 첫 행의 적립금(E)·예수금(L)이 최초 투입금액으로 잡히고, A2가 “◆ 실거래 모드 — Trades 시트 기준”, D2가 “✓ 설정 정합성 이상 없음”이면 준비 완료입니다.
📝
Trades 기록 규칙 — A:E 수량·거래금액은 매수 양수, 매도 음수(거래금액은 수수료 제외) · G:H는 적립 양수, 인출 음수(같은 줄에 동시에 쓰지 않음) · 맨 아래에 이어서 추가, 날짜순이 아니어도 되고 같은 날 여러 건은 시트가 합산합니다. 실행 후에는 VR러너가 체결·적립·인출·잔고 정렬을 자동으로 기록하므로, 사람이 적는 것은 초기 입금과 러너 밖에서 직접 한 거래·입출금뿐입니다.
💡
이미 이 종목을 보유 중이라면(다른 방식에서 옮겨오는 경우) 시작일에 두 줄을 적습니다 — A:E에 보유 주식을 매수한 것으로 1줄(수량·평단가·수수료 0·금액=수량×평단가), G:H에 주식 금액 + 현금 총액을 입금 1줄. B6도 그 총액으로 맞추면 표 첫 행의 보유 수량(J)·예수금(L)이 실제 계좌와 같아집니다.
읽기 표 읽는 법

18행부터 하루 한 줄씩 날짜·종가·RSI·신호·적립금·매매 수량·체결 단가·거래 금액·수수료·보유 수량·실현손익·예수금·합산 금액·주식비중이 쌓입니다. 표의 마지막 행이 오늘이며(한국시간 10시에 날짜가 넘어갑니다), 실거래 모드에서는 Trades 탭의 실제 기록으로 계산됩니다.

03 적립 · 인출 · 자금 이체

적립금을 정하고, 원화 자동이체 걸어두기

정기 적립을 원하면 Tracker B7에 사이클(2주)당 적립금을 적고, 그 자금을 원화로 증권계좌에 자동이체해 둡니다 — 사이클이 시작되면 VR러너가 알아서 원→달러 환전해 넣습니다. 매년 5월에는 정기 인출이 있습니다.

Tracker 정기 적립 — B7
셀이름넣을 값
B7적립 금액(사이클당)부호가 방향을 정합니다 — 양수: 적립 주기(B9, 기본 2주)마다 넣을 금액(USD, 예: $200) / 음수: 그 절대값만큼 인출(달러→원) / 0: 환전 안 함
  • 적립·인출은 사이클 시작 후 첫 거래일, 한국시간 오전 10시에 자동 처리됩니다(사이클은 B5부터 B9주 간격).
  • 적립은 원→달러 환전 후 실제로 들어온 달러를 Trades 입출금 칸에 +금액, 인출은 달러→원 환전 후 −금액으로 자동 기록합니다.
  • 한 사이클에 한 번만 환전합니다(주말·휴장이 끼어도 중복 없음). 실패하면 매매는 막지 않고 경고만 옵니다. 하루 한도(기본 $5,000)를 넘는 금액은 한도까지만 환전합니다.
자금 적립금은 원화로 자동이체 — 매주 절반씩

B7은 한 사이클(2주)치 적립금입니다. 환전 시점에 원화가 준비돼 있어야 하므로 매주 B7의 1/2을 원화로 증권계좌에 자동이체해 두는 것을 권합니다.

  • 예: B7=$200(2주치) → 매주 $100어치 원화를 증권계좌로 자동이체.
  • 원화로 넣어두기만 하면 됩니다 — 오전 10시에 VR러너가 원→달러로 환전합니다. 원화 잔고는 매일 📊 출근 리포트와 /balance로 확인할 수 있습니다.
  • 인출(B7 음수)은 원화 준비가 필요 없습니다 — 달러 예수금에서 원화로 환전됩니다.
⚠️
원화 잔액이 부족하면 그 사이클 적립 환전이 실패하고 텔레그램 경고가 옵니다 — 자동이체 금액·주기가 B7과 맞는지 확인하세요.
연 1회 예비금과 정기 인출 — 5월 마지막 수요일

매년 5월 마지막 수요일에 전년도 실현손익 × 인출률(E12, 기본 22%)을 인출합니다. 그 돈이 그날 준비돼 있도록 시트가 연초부터 예비금을 떼어 둡니다.

💡
정기 인출은 시트가 이미 예수금에서 빼 두므로 VR러너는 Trades에 기록하지 않습니다(이중 차감 방지). 원화를 은행으로 옮기는 것은 직접 하셔야 합니다. 전년도가 손실이면 목표가 0이라 묶이는 돈도 인출도 없습니다. 예비금 확보 매도를 직접 하면 그날 체결은 VR러너가 마감 10분 뒤 Trades에 기록하지만, 그 전까지는 시트와 계좌의 보유 수량이 달라 그날 VR러너 주문이 한 번 생략될 수 있습니다.
04 다운로드 & 설치

받아서 실행하면 트레이에 상주합니다

RSI-VR은 설치 과정이 따로 없는 단일 실행 파일(RSIVR.exe)입니다. 아바타 트레이(Avatar.exe)와는 완전히 별개 프로그램이라, 같은 PC에 둘 다 설치해도 서로 독립적으로 동작합니다.

  1. 릴리즈 페이지에서 최신 RSIVR.exe를 내려받습니다. 최상단 최신 릴리즈의 첨부 파일을 받으세요.
    https://github.com/gbsmfather/vr-releases/releases
  2. 받은 RSIVR.exe를 원하는 폴더(예: C:\RSIVR\)에 두고 더블클릭 — 처음 실행하면 앱을 내 PC(%LocalAppData%\VR\app)에 풀고 트레이를 띄웁니다.
  3. “Windows의 PC 보호”(SmartScreen) 경고가 뜨면 추가 정보 → 실행을 누릅니다.
  4. 작업표시줄 시계 옆 트레이에 VR 아이콘이 나타납니다(아바타 아이콘과 다릅니다). 안 보이면 ^(숨겨진 아이콘 표시)를 확인하세요. 모든 조작은 아이콘 우클릭 메뉴에서 합니다.
🔄
업데이트는 자동입니다. 트레이는 매일 프리장 시작 때 전용 릴리즈에서 새 버전을 확인하고, 있으면 묻지 않고 바로 실행 중인 VR러너를 멈추고 업데이트한 뒤 자동으로 다시 시작합니다. 다시 켜지면 텔레그램 “🚶 VR러너 출근했습니다 (… · v버전)”으로 새 버전을 확인할 수 있습니다(아바타와 같은 방식 — 릴리즈만 따로). 지금 확인하려면 우클릭 → “업데이트 확인” — 직접 누른 경우엔 [예/아니오] 창이 뜹니다. 설치 중 문제가 생기면 기존 버전으로 계속 실행하면서 알림(트레이 풍선·VR러너 봇)이 오고, 다음 프리장에 다시 시도합니다.

06 VR러너 실행

계좌를 클릭하면 러너가 시작됩니다

  1. 트레이 우클릭 → “VR러너”에 마우스를 올리면 등록된 계좌 목록이 나옵니다.
  2. 실행할 계좌 이름을 클릭 — 시작되면 메뉴에 체크 표시가 붙습니다.
  3. 기동하면 텔레그램으로 “🚶 VR러너 출근했습니다” 알림이 오고(재시작·업데이트 후에도), 상세 상태는 /status로 확인할 수 있습니다.
📈
오늘 계획·접수·체결 결과·환전은 텔레그램으로 통지되고 구글 시트(Tracker·Trades 탭)에도 기록됩니다. 프로그램 창을 열어둘 필요는 없지만 PC와 트레이는 켜 두어야 합니다(특히 장 마감 전후).
자동 자동 시작 — 트레이가 뜰 때 계좌를 자동 실행
  1. 트레이 우클릭 → “자동 시작”에 마우스를 올리면 계좌 목록이 나옵니다.
  2. 자동 시작할 계좌를 클릭해 체크합니다(다시 클릭하면 해제).
  3. 설정은 다음 트레이 실행부터 적용됩니다 — 체크된 계좌가 자동 실행되고 풍선 알림으로 알려줍니다.
💻
PC를 껐다 켜도 알아서 돌아옵니다. 설치할 때 트레이가 Windows 시작 프로그램에 등록되므로 재부팅·전원 차단 뒤 로그인하면 트레이가 자동으로 뜨고, 꺼지기 직전에 돌고 있던 VR러너를 그대로 되살립니다(직접 중지해 둔 VR러너는 되살리지 않습니다). 새벽에 Windows 업데이트가 PC를 재시작해도 그날 매매가 빠지지 않습니다. 자동 실행이 싫으면 Windows 설정 > 앱 > 시작 프로그램에서 끄면 됩니다.
관리 이름 변경 — VR러너 표시 이름 바꾸기

추가할 때 정한 이름은 나중에 바꿀 수 있습니다 — 표시 이름만 바뀌고 설정·데이터·자동 시작 여부는 그대로입니다.

  1. 바꿀 VR러너를 먼저 중지합니다(실행 중인 계좌는 목록에 나오지 않습니다).
  2. 트레이 우클릭 → “이름 변경”에 마우스를 올려 VR러너를 클릭합니다.
  3. 브라우저에 작은 입력 창이 열립니다 — 새 이름을 입력하고 저장하면 끝입니다.

자동정렬 POOL 정렬 — 시트 예수금을 실제 계좌에 맞추기

prep 때마다 시트 예수금(POOL, 표 마지막 행 L)과 계좌 달러 주문가능금액을 비교해, $0.01 이상 다르면 차액을 표 마지막 행 날짜로 Trades 입출금 칸에 부호 그대로 기록합니다(계좌가 많으면 +, 적으면 −). 수동 입출금·이자·환전 오차가 생겨도 시트가 계좌와 같아지고, 기록할 때마다 “🔧 POOL 정렬” 알림이 옵니다.

⚠️
다음 경우엔 기록하지 않고 “⚠️ POOL 자동 정렬 보류”만 알립니다 — 원인을 확인해 Trades를 직접 고쳐 주세요. ① 시트 보유 수량 ≠ 계좌 보유 수량(차액이 입출금이 아니라 빠진 체결일 가능성) ② 계좌 보유 수량 조회 실패 ③ 정기 인출일에 차액이 인출액과 똑같을 때(인출 환전이 안 됐다는 신호 — “🚨 정기인출 미실행 의심”으로 따로 알림).

07 VR러너 종료

계좌 중지 → 앱 종료, 두 단계

트레이는 실행 중인 계좌가 하나라도 있으면 종료되지 않도록 막혀 있습니다.

7-1 계좌 중지
  1. 트레이 우클릭 → “VR러너” → 실행 중(체크된) 계좌 클릭.
  2. 확인창에서 예를 누르면 중지가 시작됩니다.
  3. 진행 창이 뜨고, 정지가 끝나면 자동으로 닫힙니다.
💡
주문은 마감 60분 전에만 접수되고, LOC는 체결되지 않으면 마감과 함께 저절로 사라집니다. 다만 접수 후 마감 10분 뒤까지(한국시간 04:00~05:10) 중지하면 그날 체결 기록·결과 알림을 놓치니 이 시간대는 피하세요.
7-2 트레이 종료
  1. 모든 계좌를 중지하면 트레이 “종료”가 활성화됩니다.
  2. “종료” 클릭 → 확인창에서 예 → 트레이가 종료되고 아이콘이 사라집니다(아바타 트레이가 함께 떠 있었다면 영향받지 않습니다).
⚠️
강제 종료·전원 차단 등 정상 절차가 아닌 종료에서는, 다음 실행 시 이어서 처리됩니다(그날 처리한 단계는 반복하지 않도록 상태가 저장돼 있습니다). 종료는 반드시 위 절차를 따르세요.
🗑️
더 이상 쓰지 않는 계좌는 중지한 뒤 트레이 우클릭 → “VR러너 삭제…”에서 지울 수 있습니다(확인창이 뜨고, 그 VR러너의 설정·상태 폴더가 함께 지워집니다). 실행 중인 계좌는 삭제 목록에 나타나지 않습니다.

옮겨오기 · 문제 해결 · 주의

VR+ → RSI-VR 예전 VR에서 옮겨오기

예전 VR(VR.exe, “이얀 VR V7” 시트, 사다리 매매)은 셀 배치와 전략이 달라 RSI-VR과 호환되지 않습니다. 아래 순서로 옮기세요.

  1. 프로그램 교체 — 새 RSIVR.exe를 받아 한 번 실행하면 새 앱이 설치되고 트레이가 RSI-VR로 바뀝니다(옛 트레이의 업데이트 창에서 [예]를 눌렀다면 이미 바뀌어 있습니다). 등록한 VR러너 목록은 그대로 남습니다. 옛 VR.exe는 더 이상 동작하지 않으니 지우세요. 옛 시트로 설정된 VR러너를 새 프로그램으로 실행하면 안전을 위해 매매·환전 없이 “RSI-VR 시트가 아닙니다” 알림을 보내고 멈춥니다 — 아래 단계로 옮긴 뒤 다시 실행하세요.
  2. 새 시트 준비 — 01·02장대로 RSI-VR 시트 사본을 만들고 설정합니다. 이미 보유 중인 주식이 있으니 02장의 “이미 이 종목을 보유 중이라면” 방법으로 시작일에 보유 주식·총액을 기록하세요.
  3. VR러너 다시 등록 — 기존 VR러너를 중지 → “VR러너 삭제…” 한 뒤 “VR러너 추가…”로 같은 키움 키·봇 토큰과 새 시트 URL로 다시 등록합니다. 옛 시트 기준 진행 상태(적립 사이클 번호 등)가 남으면 새 시트에서 적립이 멈출 수 있어, 새로 등록하는 것이 안전합니다. 삭제하면 설정이 지워지니 키·토큰 값을 미리 준비해 두세요.
  4. 다른 PC 확인 — 같은 계좌를 옛 시트로 돌리던 다른 PC가 있다면 그쪽 VR러너를 끄세요. 서로 다른 시트를 보면 중복 실행 방지(_Lock)가 서로를 못 봐 주문이 이중으로 나갈 수 있습니다.
