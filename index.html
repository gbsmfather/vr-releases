01 시작 전 준비물

VR러너 추가에 필요한 자료

VR러너를 등록하기 전에 외부 서비스에서 발급·설정할 값들을 여기에 정리합니다.

✍️ 여기에 준비물 내용을 채우세요. 예) 이얀 VR V7 시트 사본, 서비스계정 JSON + 시트 공유, 키움 앱키·시크릿키(별도 계좌), 텔레그램 봇 토큰·chat_id. 카드형 그리드가 필요하면 아바타 가이드의 .prep-grid / .card 마크업을 그대로 복사해 쓰세요.
02 시트 설정

이얀 VR V7 시트 — 채울 곳

내 VR 시트 사본에서 실제로 손대야 할 칸만 안내합니다.

✍️ 여기에 시트 설정 내용을 채우세요. 스크린샷은 assets/ 폴더에 넣고 <img src="assets/파일명.png"> 로 참조합니다. 표가 필요하면 .tablewrap / <table> 마크업을 사용하세요.
03 다운로드 & 설치

받아서 실행하면 트레이에 상주합니다

VR 러너는 설치가 필요 없는 단일 실행 파일(vr.exe)입니다. 아바타 트레이와 별개로 동작합니다.

  1. 릴리즈 페이지에서 최신 vr.exe 를 내려받습니다(준비되면 여기에서 배포).
    https://github.com/gbsmfather/vr-releases/releases
  2. 받은 vr.exe 를 원하는 폴더에 두고 더블클릭해 실행합니다.
✍️ 세부 설치·SmartScreen·트레이 아이콘 안내를 여기에 채우세요. 아바타 가이드의 03 섹션 흐름을 참고하면 됩니다.
04 VR러너 추가 · 설정 마법사

준비한 값을 넣어 계좌를 등록

VR 트레이 우클릭 → “VR러너 추가…” 에서 계좌를 등록합니다.

✍️ 여기에 마법사 입력 항목을 채우세요. 항목 표가 필요하면 .tablewrap / <table> 을 사용하세요.
05 VR러너 실행

계좌를 클릭하면 러너가 시작됩니다

✍️ 여기에 실행·자동시작·텔레그램 확인 내용을 채우세요. 단계 목록은 .steps, 명령어 표는 .tablewrap 을 사용하세요.
06 VR러너 종료

계좌 중지 → 앱 종료, 두 단계

✍️ 여기에 종료 절차를 채우세요. 아바타 가이드의 06 섹션 구조를 참고하세요.
